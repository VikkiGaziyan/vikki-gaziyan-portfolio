# Vikki Gaziyan — Developer Portfolio

A responsive, animated, dark-theme developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For the best local development experience, use VS Code + Live Server.

## Before publishing — important customizations
Search these files and replace the placeholders:
- `index.html`: LinkedIn profile URL (`https://www.linkedin.com/`) and GitHub profile URL (`https://github.com/`) with your real profile links.
- Add your resume PDF in this folder and name it exactly `Vikki_Gaziyan_Resume.pdf` (or change the link in `index.html`).
- Check your phone number and email address.
- Add real project repository/demo links only if they are public and safe to share.

## Publish free with GitHub Pages
1. Create a public GitHub repository, for example `vikki-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and your resume PDF.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then **Save**.
6. GitHub will provide a public URL. Add that URL to LinkedIn, your resume and social profiles.

Alternative: drag the project folder into Netlify Drop to publish a static site.

## Notes
- No backend or database is required for this portfolio.
- The contact email link opens the visitor's email application.
- Project summaries are based on the supplied resume and intentionally avoid confidential implementation details.
- The GitHub/LinkedIn links are generic placeholders until replaced with your exact profile URLs.
